    Projects

    Hardware and software projects, built from scratch - at hackathons, for fun, at school or for competitions. I love working with my hands and building things. Most were built in a small team.

    • Blockscope (May 2022) blockchain - Crypto data analytics platform. Raised money and sold software to large institutions.

    • Chain Game (Mar 2022) blockchain - Fully on-chain game with only the UI being a web2 website. Was top 10 on the chain it's deployed on, hundreds of users. Has RNG mechanisms where each turn from a user was an on-chain transaction.

    • NftGenerator (Nov 2021) blockchain - An image processing project. Would create random NFTs at time of transaction on the blockchain based on a small set of feature sprites. Fun learning project, got interested because of NFT hype around this time.

    • ReserveBee (Apr 2021) web app - Booking and SMB sales management platform, started by selling to local barbershops.

    • Microlytics (Feb 2021) web app - A better Google Analytics for advanced webapp tracking. Google Analytics sucked, my previous projects required better monitoring. Looked around in the market, spoke with CEO of PostHog at the time and decided not worth fully pursuing, shut it down afterwards.

    • Simplemailer (Jan 2021) web app - When building out Peernet I needed to mass email all my users, a couple of thousands. I didn't like any of the existing solutions. First I made a script then I turned it into a platform that's easy to use. Worked well. Learned how pixel-based tracking for opened emails worked, that was cool.

    • EndlessJobs (Nov 2020) web app - Used to apply to many jobs. Built a Chrome extension which would remember my inputs and then auto-apply the forms on common job boards like Greenhouse, LinkedIn etc.

    • EdisonBox (Jun 2020) web app - A monthly circuit building kit. Was inspired by Tron Club, run by a Mac student. He shut it down but I wanted the service, so with my college roommate built it and shipped to buying users.

    • Dentalgo (May 2020) web app - I did AI before it was cool. Collected raw dental images, got a dentist to label the dataset, trained a model, deployed to a webapp. Would predict what teeth in an X-ray have cavities.

    • Peernet (Jan 2020) web app - Student-focused social network for universities, with all your social, academic and services needs. Finding tutors, selling used textbooks, finding off-campus housing. Free for students, monetized by charging landlords to post housing ads.

    • SAP-1 Computer (Dec 2019) hardware - Building an 8 bit computer from scratch on breadboards, was initially thinking of doing it at the transistor level but the amount of breadboards I would need was too damn high. Super fun project, got to learn about computer architecture and was able to see how the computer industry came about.

    • Crash Alert (Apr 2018) android - Android app that signals authorities when a user has been in a crash.

    • Smartvents (Oct 2017) hardware - Wifi connected vents that open/close dynamically to maintain different temperature levels in all the rooms of a house. Initially made as a prototype for an idea I was pitching. Ended up winning the competition, got funding to bring idea to life. A hardware IoT project. Idea came about from personal problems - disputes with roommates on what the apartment temperature should be.

    • Offcampushousing (May 2017) web app - Web app I built to help me find a sublet while I was not using the room in the summer. Ended up launching and have many other users.

    • Baltimore Safety Screen (Apr 2017) android - Android app that shows safety levels and high risk crime hotspots to avoid in this city.

    • MacArchives (Jul 2016) web app - Web app for university resources, has thousands of users now.

    • Quick Question (Feb 2016) web app - Web app to allow students in a lecture hall to anonymously post QnA, profs see top question from class and gives students feedback.

    • Fantasy Buddy (Oct 2015) android - Android App built to track information around the web on Football players to assist Fantasy Football.

    • Electro-mechanical Rube Goldbergs (Jun 2015) hardware - Rube Goldbergs are fun, been building them since before I knew they were called Rube Goldbergs. All my Rube Goldbergs have a high presence of lowlevel circuitry, not just mechanical energy transfers.

    • TagMe (May 2015) android - Android app built to share contact information and other social media connections by tapping phones together. Live and in the app store.

    • Recycle Rush (Apr 2015) android - Find the closest Recycling/Garbage bin near you. Used Toronto Waste Management Database. Demoed to City of Toronto Waste Management since we used their raw data to build the app.

    • FIRST Robotics & VEX Robotics (2012-2015) robotics - Built some amazing robots. My favourite seasons were Grade 10 VEX and Grade 11 VEX. Will add detail later.

    • FireFighting Robot (2014) robotics - Built a fire-truck robot that located fire in a maze and put it out.

    • Mechatronics car for P.Eng Competition (2013) robotics - Got to work with 2 of my best mates. We built an amazing small race car. Won Judge's award. I designed the electrical system from scratch, was the first time I had to really think and design a circuit from scratch.

    • 1ft Humanoid (2010) robotics - Created a robot that walks on 2 legs. Made 2 versions, one that was intricate and moves legs using a system like how pistons move and legs cross over. 2nd version where legs stay parallel, 2nd one worked better for balance.

    • Electro-mechanical Rube Goldbergs (2008/2009) hardware - Early Rube Goldberg machines built in grade 5/6.
